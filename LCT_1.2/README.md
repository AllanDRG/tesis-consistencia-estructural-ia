# LLM Consistency Toolkit 1.2

Implementación del instrumento auxiliar utilizado para aplicar criterios de evaluación y organizar registros experimentales. Esta sección reúne el código fuente, la configuración técnica y la documentación de ejecución correspondiente a la versión 1.2.

LCT asiste la puntuación y el cálculo de indicadores; la supervisión humana interviene en la consolidación de las puntuaciones oficiales. El uso del instrumento no equivale a una validación psicométrica independiente.
