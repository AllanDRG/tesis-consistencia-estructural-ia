# Documentación metodológica

Protocolo de construcción y comprobación de entradas, generación independiente de respuestas, aplicación de rúbricas, supervisión humana, consolidación de puntuaciones y tratamiento estadístico.

La trazabilidad distingue el desarrollo histórico de LCT, la calibración operativa y la evaluación definitiva. También distingue los datos conservados de las decisiones históricas cuya reconstrucción individual no es posible.
