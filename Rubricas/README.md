# Rúbricas LCT 1.2

Documentación de los criterios de evaluación de profundidad explicativa (D, C, E y A) y equivalencia conceptual de entradas (ES, EO, EC, EA y NR).

La puntuación de profundidad explicativa se expresa mediante el IPE y la de comparabilidad de entradas mediante el IEE. Los documentos describen la aplicación de las escalas y sus límites interpretativos; no representan una certificación independiente de confiabilidad.
