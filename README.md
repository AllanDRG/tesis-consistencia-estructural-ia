# Evaluacion experimental de consistencia estructural en IA

Repositorio complementario de la tesis UVG. Esta estructura distingue los datos definitivos, el instrumento LCT 1.2, la calibracion historica, las rubricas, los analisis y la documentacion.

## Carpetas

| Carpeta | Contenido previsto |
|---|---|
| `Tesis/` | Tesis en Word y posteriormente PDF oficial. |
| `Datos_Experimentales/` | Entradas, respuestas y matrices definitivas. |
| `LCT_1.2/` | Codigo, dependencias y configuraciones del instrumento. |
| `Calibracion/` | Pruebas piloto y versiones 1.0, 1.1 y 1.2, separadas del experimento definitivo. |
| `Rubricas/` | Rubricas de evaluacion de LCT 1.2. |
| `Analisis/` | Hojas de calculo y scripts estadisticos conservados. |
| `Documentacion/` | Protocolo, controles y trazabilidad. |

## Estado de los materiales

**Incluidos en este paquete:** una copia de la tesis revisada y dos rubricas editables de LCT 1.2.

## Reproducibilidad y limites

Las pruebas historicas documentan desarrollo y calibracion operativa, pero no constituyen automaticamente una validacion independiente de confiabilidad. No reconstruir valores historicos individuales del IEE ni registros de correcciones humanas como si fueran mediciones originales.
