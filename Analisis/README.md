# Análisis estadístico

Organización de las matrices analíticas, cálculos de IPE, diferencias pareadas (ΔIPE y |ΔIPE|), equivalencia agregada y dimensional, resultados descriptivos, contrastes t pareados y análisis complementarios.

Los resultados de cada sistema se procesan por separado. Las pruebas de diferencia media no sustituyen el análisis descriptivo de los perfiles dimensionales ni prueban equivalencia estadística.
