# Datos experimentales

Conjunto definitivo de 200 pares de entradas conceptualmente equivalentes utilizado en ambos sistemas. La organización distingue las entradas A y B, las respuestas originales, los identificadores de caso y las matrices definitivas de puntuaciones de profundidad explicativa.

Cada sistema aporta 200 pares de respuestas (400 respuestas individuales). Los conjuntos se analizan por separado. Los valores históricos individuales del IEE no forman parte de la matriz definitiva y no deben reconstruirse como mediciones originales.
