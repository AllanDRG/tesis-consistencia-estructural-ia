# Calibración y desarrollo de LCT

Registro histórico de las pruebas piloto y de las versiones 1.0, 1.1 y 1.2. Los bancos históricos documentan el desarrollo iterativo, la revisión de criterios y la calibración operativa del instrumento.

Estos registros se mantienen separados de las observaciones definitivas y no se suman automáticamente como casos independientes ni se presentan como prueba de confiabilidad estadística formal.
